Checks supplied data. Live event retrieval and production feed integration are outside this demo.

Inside the buildA Lisbon field note + the design choices

One set of rules.

The browser runs the same Python checker as the downloadable package. Findings can be exported as JSON or Markdown and traced to a record.

A small, reproducible case.

Three public Lisbon listings exposed a gap in our import: nine timestamps lacked a UTC offset. Explicit time-zone normalization removed those nine errors. This measures our import correction, not an error by the organizers.

Evidence has limits.

Related publisher pages are not independent corroboration. A clean report does not establish ticket availability or that an event will happen.

NIVQRA

Before an agent acts,
make authority inspectable.

Who is the agent acting for? What can it do? Where must a human intervene? Authority Review turns a structured brief into documents a team can inspect together.

THE PRODUCT DECISION

Keep limits, approval owners and unresolved decisions explicit. An unknown should stay visible.

Try NIVQRA ↗Read the source ↗

Every output is DRAFT · NOT ACTIVE. This authoring tool does not grant authority, enforce policy or execute payments.

Inside the buildSeparate owners + four review files

Ownership is specific.

The person approving a larger amount may differ from the person approving a new counterparty. One name cannot silently fill both responsibilities.

A reviewable handoff.

A guided brief produces an inactive mandate, a permission matrix, scenario specifications and a readable review. The browser uses the original Python compiler.

Draft means draft.

Scenario specifications are marked not run. They need testing against the actual implementation; generating the documents never activates authority.
